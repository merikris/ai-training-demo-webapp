# Testiplaani näidis — AI Training Demo Webapp

Kasuta seda dokumenti Claude Projecti harjutuses (individuaalne, Plokk D), kui sul
pole endal käepärast testiplaani ega spetsifikatsiooni. Laadi see fail üles oma
Claude Projecti ja palu genereerida testjuhtumeid, kokkuvõtteid või lünkade analüüs
selle põhjal.

| Funktsioon | Testisamm | Oodatud tulemus |
| --- | --- | --- |
| Sisselogimine | Sisesta õige e-mail ja parool | Kasutaja jõuab avalehele |
| Sisselogimine | Sisesta vale parool | Kuvatakse veateade |
| Otsingufiltrid | Vali hinnavahemik ja saadavus | Tulemused uuenevad ilma lehte laadimata |
| Otsing | Otsi olemasolevat toodet | Tulemused kuvatakse 2 sekundi jooksul |
| Korv | Lisa toode korvi | Korvi ikoon näitab õiget kogust |

See on üldine testiplaani näidis (mitte otseselt selle demo-rakenduse enda
funktsioonide kirjeldus) — kasuta seda ainult sisendina Claude Projecti harjutuse
jaoks, kui vajad päris dokumenti üleslaadimiseks.
