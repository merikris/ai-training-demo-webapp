# Sessioon 3 fallback-pakk — kasutusjuhend treenerile

Kõik dokumendid on fiktiivsed, aga sidusad — nad kirjeldavad sama väljamõeldud
"maksevoo moodulit" ja lingivad omavahel (spekk → testiplaan → bug report → API),
täpselt nagu päris ASA projektis. Kasuta neid osalejatele, kellel pole hetkel oma
projekti materjali käepärast.

## Failid ja millise harjutusega need käivad

| Fail | Harjutus | Kuidas kasutada |
|---|---|---|
| `1_Maksevoo_mooduli_spetsifikatsioon.md` | Gemini Notebook praktika (Plokk B) | Lae üles koos testiplaani ja API kirjeldusega, küsi edge case'ide kohta |
| `2_Maksevoo_testiplaan.md` | Gemini Notebook praktika | Sama — laadi koos spetsifikatsiooniga |
| `3_Bug_report_topeltmakse.md` | Gemini Notebook praktika | Sisaldab stack trace'i — hea "kontrolli viidatud allikat" näide |
| `4_Maksevoo_API_kirjeldus.md` | Claude Projects praktika (Plokk D) | Üks kolmest "päris dokumendist", mida Projecti lisada |
| `5_Naidispiletid_Jira.md` | Atlassian AI praktika (Plokk C) | Kopeeri "piletid" oma AI-tööriista — PROJ-101/102 on tahtlik duplikaadipaar |

## Miks "maksevoog"

Sama fiktiivne moodul, mida mainiti juba Ploki B "halb vs hea küsimus" näites
("Millised 5 edge case'i mõjutavad maksevoogu...") — osalejad on selle konteksti
juba korra näinud, mis teeb fallback-materjali kasutamise loomulikumaks.

## Kui osalejal on oma materjal

Fallback-pakk on ainult varuvariant — julgusta osalejaid alati kõigepealt oma päris
projekti dokumente kasutama, kui need on käepärast.
